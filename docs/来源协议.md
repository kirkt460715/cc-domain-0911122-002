# 仪表工作簿
python3 -m lab.workbooks /tmp/workbooks 产生两本独立 .xlsx，分别声明 1900 和 1904 日期体系。测量表 A:E 对应事件编号、别名、本地时间、原始值、fold；仪表表将别名映射到设备和单位。来源时区 America/New_York。数据是合成仪表记录：字符串事件号有前导零，sharedStrings 与 inlineStr 混用；C 列允许 ISO 当地时间或 Excel 数字日期，D 列包含有/无缓存的公式。空 fold 表示未给消歧信息。conflict 有两条配置，序号 60 用于呈现日期体系差别。工作簿不含宏、外链或真实数据。
演示范围只要求 xlsx 的工作簿关系、两个 sheet、共享字符串、单元格类型和公式缓存；不要求图表、富文本格式或 Excel 计算引擎。python3 -m lab.demo 查看结构。原有设备注册、有效期与校准可通过现有 commands 入口配置。
