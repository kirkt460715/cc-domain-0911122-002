# 仪表工作簿
python3 -m lab.workbooks /tmp/workbooks 产生两本独立 .xlsx，分别声明 1900 和 1904 日期体系。测量表 A:E 对应事件编号、别名、本地时间、原始值、fold；仪表表将别名映射到设备和单位。来源时区 America/New_York。数据是合成仪表记录：字符串事件号有前导零，sharedStrings 与 inlineStr 混用；C 列允许 ISO 当地时间或 Excel 数字日期，D 列包含有/无缓存的公式以及缓存为错误值 #DIV/0! 的公式。空 fold 表示未给消歧信息；0008 行在夏令时重叠时刻故意不给 fold。conflict 有两条配置，序号 60 用于呈现日期体系差别。工作簿不含宏、外链或真实数据。
演示范围只要求 xlsx 的工作簿关系、两个 sheet、共享字符串、单元格类型和公式缓存；不要求图表、富文本格式或 Excel 计算引擎。python3 -m lab.demo 查看结构与完整采集流程。原有设备注册、有效期与校准可通过现有 commands 入口配置。

# 工作簿采集
hangar_ingest 直接读取 .xlsx：preview 按采集规则（工作表、字段、IANA 时区）展示每行转换结果、工作表/单元格/原值证据以及接收或隔离预判；confirm 校验原始工作簿摘要、解析规则与引用的配置版本，过期或配置已变化的预览会被拒绝，不会换用新规则悄悄落库。公式只读取现存缓存，缺缓存或错误值的行进入隔离待处理，不重算。确认后的批次走既有设备映射、校准、隔离与批次处理，相同来源事件按既有身份去重。CSV/NDJSON 入口保持不变。
